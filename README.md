# Shadows of Doubt — Trainer

Внешний трейнер для **Shadows of Doubt** (одиночная игра). Это один `exe`: без модов, без MelonLoader / BepInEx, ничего не устанавливается в папку игры и файлы игры не изменяются.

> *English:* a standalone external trainer for the single-player game Shadows of Doubt. It reads/writes the game process memory, needs no mod loader and installs nothing into the game folder. UI language: Russian.

## Возможности

### Дело
- **Имя убийцы** крупно + кнопка «Копировать имя»
- Дом убийцы, работа (должность и компания), логово, **где он находится прямо сейчас**
- Тип убийцы, оружие, «визитка»
- Жертва: имя, дом, работа, место убийства
- Виновный и заказчик открытого побочного дела

### Игрок
- Деньги, отмычки, социальный рейтинг: установить / добавить / быстрые «+» / **заморозить**
- Полное здоровье и нервы, пополнение потребностей, снятие недугов
- Бессмертие (здоровье всегда полное)
- «Без нелегальных действий» (игра не считает действия незаконными)
- Без голода, жажды, усталости и болезней

### Читы
- Неуязвимость, невидимость для NPC, бесшумность, без урона от падения
- Заморозка всех NPC (пауза ИИ), доступ куда угодно (trespass), всегда бежать
- Ключи от всего города, доступ в больницы
- Скорость движения, сила отмычки, множитель наград за дела
- Фиксированный код для кодовых замков
- Отладочные опции игры (помечены «экспер.»): открыть все комнаты, раскрыть все улики, все улучшения, свободная камера, ускорение времени

### Журнал
- События подключения и кнопка «Сохранить диагностику в файл»

## Использование

1. Скачайте `ShadowsOfDoubtTrainer.exe` из раздела [Releases](../../releases) (или соберите сами, см. ниже).
2. Запустите игру и **загрузите сохранение** — на главном меню игровых объектов ещё нет. Трейнер можно запускать до или после игры.
3. Если трейнер не подключается — запустите его от имени администратора.

Windows, 64-бит. Нужен .NET Framework 4.x (есть в Windows 10/11).

## Как это работает

Трейнер не использует фиксированные адреса или сигнатуры кода. Он:

1. находит в памяти игры `global-metadata` (IL2CPP) и по именам классов ищет структуры `Il2CppClass`;
2. по именам полей читает смещения из `FieldInfo` (с учётом наследования);
3. берёт синглтоны (`Game`, `GameplayController`, `Player`, `MurderController`, …) из статических полей `_instance`;
4. читает и пишет значения полей (`money`, `invisiblePlayer`, `currentMurderer.citizenName`, …).

Благодаря этому смещения не зашиты в код и после обновлений игры всё должно продолжать работать, пока разработчики не переименуют сами поля или классы.

Проверено на: Shadows of Doubt (Steam), Unity 2021.3.45f2, ноябрь 2026.

## Сборка

Нужен только компилятор C# — из Visual Studio Build Tools (Roslyn) или из .NET Framework 4.x. .NET SDK не требуется.

```bat
build.bat
```

Результат: `ShadowsOfDoubtTrainer.exe` рядом со скриптом. Для самопроверки на запущенной игре: `ShadowsOfDoubtTrainer.exe --selftest out.txt`.

## Ограничения

- **Телепортов нет.** Позиция игрока хранится во внутреннем объекте Unity, а вызывать методы игры из внешней программы без инжекта кода нельзя.
- Опции с пометкой «экспер.» — это отладочные флаги самой игры, их влияние на прогресс не проверялось.
- Запись в память игры может привести к неожиданному поведению: **делайте резервные копии сохранений**. Используйте только в одиночной игре.

## Об авторстве

Это **самостоятельный проект, а не форк**: код написан с нуля. Идея набора функций появилась на основе мода
ShadowsOfDoubtModMenu (авторы Glumboi и Linkis, MIT) — он работал через MelonLoader и был рассчитан на более старую версию игры. Код этого мода здесь не используется.

Проект не связан с разработчиками Shadows of Doubt (ColePowered Games) и не содержит файлов игры.
